# 华文B：词语记忆挑战

100-question, four-choice Chinese B vocabulary and comprehension game. Odd-numbered questions use Chinese contexts; even-numbered questions ask for the meaning of a phrase in English. Each answer includes a short English explanation and Hanyu Pinyin.

This is a buildless static site for GitHub Pages. Publish from the `main` branch at `/(root)`; `index.html`, `extra.js`, and `.nojekyll` must stay together.

The practice questions are adapted from the A-Level Chinese B Paper 2 documents supplied by the site owner. Comprehension and recall questions are practice questions, not official examination items.
